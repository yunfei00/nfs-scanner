# Done Checklist

A task is done when:

- app imports successfully
- existing startup is preserved
- existing scan logic is preserved
- task acceptance criteria are met
- product spec is followed
- architecture docs are followed
- change is committed

For UI tasks:

- 1366x768 is usable
- 1920x1080 is comfortable
- central workspace keeps priority
- right panels scroll when needed
- theme rules are followed

For visualization tasks:

- overlay layers stay aligned
- heatmap uses one image layer
- zoom and pan work together

After each task, record:

- summary
- files changed
- checks
- limitations
- next task
