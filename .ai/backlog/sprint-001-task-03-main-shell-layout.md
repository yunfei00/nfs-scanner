## Goal

Implement the first commercial main shell layout with placeholders.

## Read First

## Scope

Create a shell with:

- top toolbar
- left area
- central workspace
- right property panel
- bottom dock
- status bar

Use placeholders only.

## Acceptance

- Layout opens without runtime errors.
- Central workspace has highest stretch priority.
- 1366x768 is usable.
- 1920x1080 is comfortable.
- No existing scan logic is changed.
