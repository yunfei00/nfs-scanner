# Sprint 001 Task 02 - Theme System

## Goal

Add the first dark professional theme for the commercial UI.

## Read First

- `docs/product-spec/01_design_system.md`
- `docs/development/qt_guidelines.md`

## Scope

- Add a QSS file for dark professional theme.
- Add a small theme loader if needed.
- Apply the theme only where safe.
- Avoid hard-coded colors in new UI files.

## Acceptance

- New commercial UI can load the theme.
- Buttons, cards, inputs and tabs have consistent appearance.
- Existing UI remains readable.
- App still starts.
