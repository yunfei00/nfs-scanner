# UI Review Checklist

Use this checklist when reviewing commercial UI changes.

## Checks

- Does the UI follow `docs/design-system/`?
- Does the central canvas keep layout priority?
- Is the right-side panel scrollable?
- Is the UI usable on small screens?
- Are controls reused instead of duplicated unnecessarily?
- Are colors hard-coded in Python?
- Are object names or dynamic properties available for QSS/theme styling?
- Does the old UI remain available?

## Result

Record:

- UI issues.
- Theme/design-system gaps.
- Small-screen risks.
- Follow-up tasks.
