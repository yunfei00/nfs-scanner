# 真实硬件手工验收

## 启动

```powershell
python -m nfs_scanner
```

## 运动平台

1. 确认急停和机械限位可用。
2. 在“串口设置”选择端口和波特率，点击“打开串口”。
3. 执行“位置查询”和“读取版本”。
4. 使用最小点动步距验证 X/Y/Z 方向。
5. 验证越界目标被拒绝。
6. 验证“停止”能中断扫描。

## 频谱仪

1. 点击“搜索仪表”。
2. 确认目标型号标签显示正确资源。
3. 查询起始/终止频率、RBW 和点数。
4. 使用安全参数执行一次数据保存。

## 小范围扫描

1. 设置 2–3 个扫描点的小区域。
2. 检查输出目录可写。
3. 执行扫描并观察位置、进度、剩余时间和日志。
4. 检查计划快照、执行快照和测量结果。
5. 测试暂停、继续与停止。

任何方向、限位、急停或状态反馈异常都必须立即停止验收。
