# Resume Project Description

## NFS Scanner - Near Field Scan Automation Platform

Role: System Architect / Core Developer

Tech Stack:
Python, PySide6, VISA, SCPI, NumPy, Qt Graphics View

Project Description:
Designed and developed an industrial near-field scan automation platform integrating motion control, spectrum acquisition, data processing and visualization.

Key Contributions:

- Designed unified instrument abstraction architecture.
- Integrated FSW, N9020A and ZNA67 instruments.
- Built ScanManager lifecycle framework.
- Implemented automated acquisition workflow.
- Established heatmap analysis pipeline.
- Planned migration path to Qt/C++ architecture.

Project Value:

Improved test efficiency, reduced manual operations, and established a reusable platform foundation for future RF automation systems.
