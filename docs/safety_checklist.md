# 真实设备安全检查清单

## 启动前

- [ ] 操作人员在设备旁，急停可立即触达。
- [ ] 平台路径无人员、线缆和障碍物。
- [ ] 机械限位、软限位和坐标方向已经验证。
- [ ] 串口、波特率和设备身份正确。
- [ ] 仪表资源、频率范围和输入保护正确。
- [ ] 输出目录可写且磁盘空间足够。

## 首次动作

- [ ] 先查询位置和版本，不直接开始扫描。
- [ ] 使用 0.01 mm 或 0.1 mm 点动确认方向。
- [ ] 使用 2–3 点小范围扫描确认完成条件。
- [ ] 验证暂停、继续、停止和急停行为。

## 自动化

- [ ] 普通测试不设置真实设备环境开关。
- [ ] 不在无人值守环境运行真实硬件脚本。
- [ ] 不为通过测试绕过软限位或确认门禁。
