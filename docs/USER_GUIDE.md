# NFS Scanner 用户指南

## 1. 启动前检查

1. 确认运动平台工作区域无人、无障碍物，物理急停可用。
2. 安装设备厂商要求的串口驱动。
3. 仪表通过 VISA 通信时安装 NI-VISA；软件检测不到 VISA 后端时只会跳过搜索，不会影响串口页面启动。
4. 不要同时启动两个 NFS Scanner 实例。

## 2. 连接运动设备

软件启动时只枚举串口，不会自动打开真实控制通道。选择正确端口和波特率后点击“打开串口”，阅读安全确认并确认。设备掉线后软件只监控端口是否恢复，不会自动重新连接。

## 3. 停止与急停

- “停止”会在当前安全检查点结束扫描并保存已完成数据。
- “软件急停”会尽快向控制器发送复位停止命令，随后任务进入故障停止状态。
- 软件急停不是安全认证的物理急停替代品。人员或设备存在风险时必须使用设备的物理急停。

## 4. 数据位置

默认扫描目录为用户“文档/NFSScanner/Scans”。应用配置保存在用户 AppData 目录，安装目录保持只读。每次扫描目录包含：

- `scan_manifest.json`：任务、版本、设备和进度清单；
- `scan_plan_points.csv`：规划路径；
- `scan_executed_points.csv`：已完成路径；
- `instrument_scan_data/`：逐点仪表数据和索引；
- `checksums.sha256`：任务完成后的文件校验清单。

异常退出后，下一次启动会把遗留的 `running` 任务标记为 `interrupted`，已有逐点数据不会删除。

## 5. 仪表数据

真实仪表查询失败时界面显示“查询失败”，不会使用模拟参数替代。只有勾选“模拟频谱仪”时频谱数据来自 Mock 适配器，运动平台仍为真实设备。

## 6. 技术支持

点击“导出诊断”生成支持 ZIP。诊断包包含版本、近期日志和脱敏配置，不包含扫描测量数据。发送诊断包前仍应按单位的数据安全要求复核内容。
