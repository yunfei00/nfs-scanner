# 02 Main Window Layout

## 1. 总体布局

主窗口采用商业仪器软件布局：

```text
┌──────────────────────────────────────────────────────────────┐
│ Top Bar / Toolbar                                             │
├──────────────┬───────────────────────────────┬───────────────┤
│ Workflow     │ Workspace                     │ Property      │
│ + Devices    │                               │ Panel         │
│              │                               │               │
├──────────────┴───────────────────────────────┴───────────────┤
│ Bottom Dock: Spectrum / Statistics / Logs                     │
├──────────────────────────────────────────────────────────────┤
│ Status Bar                                                    │
└──────────────────────────────────────────────────────────────┘
```

## 2. Top Bar / Toolbar

### 2.1 左侧品牌区

显示：

- NFS Logo
- 近场扫描系统
- Near Field Scanner
- 版本号

### 2.2 主工具按钮

按钮顺序：

1. 新建项目
2. 打开项目
3. 保存项目
4. 连接设备
5. 开始扫描
6. 停止扫描
7. 拍照
8. 区域对齐
9. 清除覆盖
10. 导出数据
11. 导出报告
12. 参数模板
13. 帮助

### 2.3 右侧状态区

显示：

- 授权状态
- 当前用户
- 窗口控制按钮

## 3. 左侧 Workflow + Device Area

### 3.1 Workflow 步骤

固定步骤：

1. 项目管理
2. 设备连接
3. 区域标定
4. 扫描配置
5. 扫描执行
6. 数据分析
7. 报告导出

每个步骤需要：

- 编号
- 标题
- 描述
- 状态：未开始 / 进行中 / 已完成 / 错误
- 当前步骤高亮

### 3.2 设备状态

显示三类设备：

- 运动平台
- 频谱仪
- 相机

每个设备卡片显示：

- 设备名称
- 型号/协议
- 连接地址
- 状态 Badge
- 关键参数摘要

### 3.3 响应式折叠

当窗口宽度小于 1500px：

- Workflow 宽度从 260px 折叠到 56px。
- 只显示步骤编号和状态点。
- 鼠标悬停显示完整信息 Tooltip。

## 4. 中央 Workspace

Workspace 是主操作区，必须占据最大面积。

### 4.1 顶部 Tab

固定 Tab：

- 实时视图
- 数据视图
- 3D 视图
- 数据表格

后续可扩展：

- 报告中心
- 设备中心

### 4.2 视图工具栏

每个工作模式可有自己的工具栏。

实时视图工具栏：

- 选择
- 平移
- 缩放
- 框选
- 多边形
- 撤销
- 重做
- 标注
- 网格
- 路径
- 测量
- 透明度
- LUT

## 5. 右侧 Property Panel

右侧面板采用 Tab：

- 扫描参数
- 显示设置
- 仪表设置

### 5.1 扫描参数

包含：

- 扫描区域
- 扫描设置
- 频率设置
- 开始/停止按钮

### 5.2 显示设置

包含：

- 热力图开关
- 透明度
- LUT
- vmin/vmax
- 插值方式
- Colorbar
- Grid
- Marker

### 5.3 仪表设置

包含：

- 频谱仪类型
- Trace
- Start/Stop/Center/Span
- RBW/VBW
- Points
- ATT/Preamp
- Detector/Average

## 6. Bottom Dock

底部 Dock 包含：

- 频谱视图
- 频谱对比
- 频谱标记
- 扫描统计
- 日志

大屏模式：频谱、统计、日志可并排显示。

小屏模式：底部 Dock 自动切换为 Tab，一次只显示一个内容。

## 7. Status Bar

状态栏显示：

- 系统状态
- 当前项目
- 当前任务
- 扫描进度
- 授权类型
- 剩余天数
- 当前日期时间

## 8. 分辨率适配验收标准

### 8.1 1366×768

- 中央画布可见且可操作。
- 左侧自动折叠。
- 右侧可滚动。
- 底部为 Tab 模式。
- 所有关键按钮可访问。

### 8.2 1920×1080

- 左侧完整显示。
- 右侧完整显示。
- 底部频谱、统计、日志可并排显示。
- 中央画布宽度不小于窗口宽度的 45%。

## 9. 实现建议

- 使用 `QMainWindow + QDockWidget + QSplitter`。
- 中央区域使用 `QTabWidget` 或自定义 TabBar。
- 左、右、底部区域允许保存布局状态。
- 使用 `QSettings` 保存用户上一次布局、折叠状态和主题。
