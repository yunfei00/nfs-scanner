# 00 Product Vision

## 1. 产品定位

NFS Scanner 是一套面向 EMC、射频调试、天线近场测试、汽车电子与实验室自动化场景的企业级近场扫描系统。

它不是单一调试工具，而应演进为：

> FlyCloud Near Field Studio：设备控制 + 扫描执行 + 数据分析 + 报告生成的一体化工程平台。

## 2. 核心价值

- 自动控制运动平台，减少人工移动与记录。
- 自动采集频谱数据，保证重复性和可追溯性。
- 使用相机照片 + 热力图叠加，让热点定位更直观。
- 支持实时扫描和离线分析。
- 支持多厂商频谱仪，通过插件机制扩展。
- 支持自动报告，减少工程师后处理时间。

## 3. 目标用户

### 3.1 主用户

- EMC 测试工程师
- 射频工程师
- 天线工程师
- 汽车电子测试工程师
- 实验室技术员

### 3.2 管理用户

- 实验室负责人
- 项目经理
- 售前/交付工程师

## 4. 产品体验目标

软件打开后的第一视觉中心必须是：

1. 被测物相机照片
2. 扫描区域
3. 扫描路径
4. 热力图叠加
5. 当前 Marker 数据

用户不应该先看到大量串口命令、日志或复杂参数。

## 5. 设计关键词

- 专业
- 稳定
- 清晰
- 高信息密度
- 可折叠
- 可追溯
- 可扩展
- 仪器软件风格

## 6. 成功标准

### 6.1 商业展示成功标准

客户第一次看到界面时，应能理解：

- 这是一套专业近场扫描软件。
- 它能把 PCB/被测物照片与电磁热力图叠加。
- 它能控制运动平台、频谱仪和相机。
- 它能生成结果和报告。

### 6.2 工程实现成功标准

- 所有主功能可在 1366×768 分辨率下使用。
- 1920×1080 下布局完整舒适。
- 所有参数区域可滚动或折叠。
- 中央画布始终拥有最高空间优先级。
- 扫描过程中 UI 不阻塞。
- 日志、数据、任务可追溯。

## 7. 非目标

当前阶段不追求：

- 云平台协同。
- 多用户权限系统。
- 真正 3D PCB 模型加载。
- 大规模数据库服务器。

这些能力可以作为后续产品线扩展。
