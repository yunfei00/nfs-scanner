# 03 Work Modes

## 1. 概述

主工作区包含四个核心工作模式：

1. 实时视图 Real-time View
2. 数据视图 Data View
3. 3D 视图 3D View
4. 数据表格 Data Table

后续扩展两个高级模式：

5. 报告中心 Report Center
6. 设备中心 Device Center

每个工作模式只服务一种主任务，避免一个页面同时承担过多功能。

---

# 2. 实时视图 Real-time View

## 2.1 目标

用于扫描前对齐、扫描执行、实时热力图展示和当前点观察。

这是用户最常使用的页面。

## 2.2 画布图层

中央画布使用 QGraphicsView/QGraphicsScene，按层级显示：

1. `PhotoLayer`：相机照片或导入图片。
2. `HeatmapLayer`：热力图 RGBA 图片。
3. `ScanPathLayer`：扫描轨迹、蛇形路径、当前行。
4. `MarkerLayer`：Marker、Tooltip、光标。
5. `AnnotationLayer`：测量线、标注、比例尺、坐标轴。

## 2.3 基本交互

- 鼠标滚轮：缩放。
- 中键/空格+左键：平移。
- 左键：选择对象或 Marker。
- 右键：上下文菜单。
- 双击：重置视图或聚焦 Marker。

## 2.4 工具栏功能

- 选择
- 平移
- 缩放
- 框选矩形
- 多点标定
- 撤销
- 重做
- 标注
- 网格
- 路径
- 测量
- 截图
- 透明度
- LUT

## 2.5 Marker

支持：

- 添加 Marker
- 删除 Marker
- 移动 Marker
- Marker 列表
- 多 Marker 比较
- 显示 X/Y/Z/Frequency/Amplitude/Phase

## 2.6 实时扫描显示

扫描过程中显示：

- 当前点
- 已完成点
- 扫描路径
- 当前行
- 热力图增量更新
- 当前频谱点
- 预计完成时间

## 2.7 验收标准

- 照片、热力图、路径同步缩放和平移。
- 热力图为整张 QImage/QPixmap，不允许单格绘制导致缝隙。
- 可在 1366×768 下正常查看中心画布。
- 扫描过程中 UI 不阻塞。

# 3. 数据视图 Data View

## 3.1 目标

用于扫描完成后的离线分析。

用户可以加载历史任务，选择 Trace、频率、显示模式、LUT，并重新生成热力图。

## 3.2 页面结构

左侧：任务列表。

中间：离线热力图视图。

右侧：分析参数。

底部：频谱、统计、日志。

## 3.3 功能

- 按项目/日期/任务筛选扫描数据。
- 加载历史扫描任务。
- 选择 Trace。
- 选择频率。
- 显示模式：幅度、幅度 dB、相位、实部、虚部。
- LUT 切换。
- vmin/vmax 自动/手动。
- 插值方式切换。
- 导出 PNG/TIFF/CSV/PDF。

## 3.4 验收标准

- 不依赖真实设备即可打开历史数据。
- 可以反复切换频率和 Trace。
- 切换 LUT 不改变原始数据。
- 导出图像与当前显示一致。

# 4. 3D 视图 3D View

## 4.1 目标

用三维形式展示热力图强度分布，方便客户演示热点趋势。

## 4.2 V1 范围

V1 不做真实 PCB 3D 模型，仅做 XY 网格 Surface：

- X/Y 代表扫描平面坐标。
- Z 高度代表幅度或幅度 dB。
- 颜色代表 LUT 映射值。

## 4.3 功能

- 旋转
- 平移
- 缩放
- Surface / Wireframe 切换
- 颜色条
- 视角重置
- 导出图片

## 4.4 后续版本

V2：Mesh 优化和多层数据显示。

V3：导入 PCB 图片作为底面纹理。

V4：支持 STL/OBJ 简化模型。

## 4.5 验收标准

- V1 可以从当前热力图矩阵生成三维 Surface。
- 旋转和平移流畅。
- 小屏下可隐藏右侧参数，仅保留 3D 区域。

# 5. 数据表格 Data Table

## 5.1 目标

为企业客户提供可追溯、可检索、可导出的扫描点数据。

## 5.2 表格字段

基础字段：

- Point ID
- X
- Y
- Z
- Timestamp
- Trace
- Frequency
- Magnitude
- Magnitude dB
- Phase
- Real
- Imag

## 5.3 功能

- 排序
- 过滤
- 搜索
- 选中点联动 Marker
- 导出 CSV/Excel
- 复制选中数据
- 显示单点完整频谱

## 5.4 验收标准

- 10 万行以内表格可流畅滚动。
- 选中任意点后，实时视图和频谱视图能定位到该点。
- 导出的 CSV 字段稳定。

# 6. 报告中心 Report Center

## 6.1 目标

自动生成客户可交付报告，减少工程师后处理工作。

## 6.2 报告内容

- 封面
- 项目信息
- 设备信息
- 扫描参数
- 相机照片
- 热力图
- 频谱图
- Marker 表格
- 统计信息
- 结论备注

## 6.3 导出格式

- PDF
- Word
- HTML
- Markdown

## 6.4 V1 策略

V1 先实现模板化 PDF，不做完整所见即所得编辑器。

---

# 7. 设备中心 Device Center

## 7.1 目标

将复杂设备配置从主扫描界面剥离出来，让主界面保持清爽。

## 7.2 模块

- Motion：运动平台
- Spectrum：频谱仪
- Camera：相机
- License：授权
- Plugin：插件
- Calibration：校准

## 7.3 功能

- 设备搜索
- 连接测试
- 参数模板
- 设备日志
- 插件加载
- 授权导入
- 校准配置

## 7.4 验收标准

- 主界面只展示设备状态摘要。
- 复杂配置在 Device Center 完成。
- 新设备插件能在设备中心被发现和启用。
