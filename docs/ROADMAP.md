# 商业基线后续路线

当前代码库以单界面、单设备入口、单扫描 Worker 和可恢复数据目录作为唯一基线。

## 1.0 发布前外部事项

- 使用目标运动平台、ZNA67、N9020A、FSW 完成硬件验收矩阵并保存证据。
- 确认设备驱动、VISA 后端与支持的 Windows 版本组合。
- 提供正式公司名称、版权主体、产品图标和 Authenticode 代码签名证书。
- 由法务确认 PySide6/Qt 的商业或开源合规路径及第三方许可证文本。
- 在干净 Windows 设备验证安装、升级、卸载、日志、数据目录与崩溃恢复。

## 后续功能

- 基于现有扫描会话格式实现结果浏览和热力图，不改变设备采集链路。
- 增加扫描中断后的人工确认续扫能力，并保留完整审计记录。
- 按真实硬件验收结果扩展设备健康状态、校准记录和维护提示。
- 增加发布版本回滚说明与客户现场诊断流程。

任何新增页面都必须位于当前 `MainWindow` 下，任何新增设备都必须接入现有
`DeviceManager`，不得恢复平行 UI、Provider 或扫描状态机。
