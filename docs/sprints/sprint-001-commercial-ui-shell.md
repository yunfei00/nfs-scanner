# Sprint 001 - Commercial UI Shell

## Goal

Build the first commercial UI shell without changing existing scan logic.

## Outcome

The app can show a new commercial layout with placeholder regions:

- top toolbar
- left workflow
- device status cards
- workspace tabs
- right property panel
- bottom dock
- status bar

## Tasks

1. Create commercial UI package.
2. Add theme loader and dark professional QSS.
3. Add main shell layout.
4. Add workflow and device status panels.
5. Add workspace tabs with placeholder views.
6. Add property panel and bottom dock.
7. Add startup toggle or safe entry point.

## Rules

- Do not delete old UI.
- Do not connect real hardware in this sprint.
- Use placeholders and mock status values.
- Keep the app startup working.
- Follow docs/product-spec and docs/architecture.

## Acceptance

- App starts.
- New shell can be opened.
- 1366x768 is usable.
- 1920x1080 is comfortable.
- Old scan UI remains available.
