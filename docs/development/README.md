# Development Guide

This directory contains engineering rules for implementing NFS Scanner.

## Documents

- `coding_style.md` - Python and project coding style.
- `qt_guidelines.md` - PySide6 and Qt UI implementation rules.
- `testing.md` - testing and verification strategy.
- `release_process.md` - future release checklist.

## Rule

When a development guide conflicts with the product spec, follow the product spec and update the guide.
