# Typography

商业版 UI 的字体规则应优先保证工程工具的可读性、长时间使用舒适度和中英文混排稳定性。

## Font Families

- 中文优先：`Microsoft YaHei UI`
- 英文和数字优先：`Segoe UI`
- 日志与坐标等宽文本：`Consolas` / `Cascadia Mono`

## Text Styles

| Style | Size | Weight | Usage |
|---|---:|---:|---|
| 产品标题 | 18px | 700 | 顶部品牌区、主窗口产品名。 |
| 面板标题 | 14px | 600 | 左右面板、Dock、参数分组标题。 |
| 正文 | 13px | 400 | 常规说明、表单内容、面板正文。 |
| 标签 | 12px | 400 | 参数名、字段名、辅助标签。 |
| 数值 | 13px | 600 | 坐标、频率、幅度、进度等关键值。 |
| 日志等宽字体 | 12px | 400 | 日志、SCPI 文本、设备原始响应、坐标列表。 |

## Rules

- 中文界面文案优先使用简洁、明确的工程语言。
- 数字、单位和坐标应尽量使用等宽或稳定宽度显示，避免刷新时界面跳动。
- 日志视图必须使用等宽字体。
- 不使用过大的营销式标题，工具面板内标题应紧凑。
- 禁止在局部 Widget 中随意定义独立字体体系。
