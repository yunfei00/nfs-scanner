# FlyCloud Near Field Studio / NFS Scanner V1.0 Master Roadmap

This directory is the entry point for the V1.0 master roadmap of FlyCloud Near Field Studio / NFS Scanner.

It defines the high-level product delivery path, milestones, and dependency order. It is not a daily task list and should not be edited frequently.

After this roadmap is complete, day-to-day execution should happen through sprint documents and `.ai/backlog/` tasks.

## Documents

- `v1_roadmap.md` - V1.0 phase overview.
- `milestones.md` - V1.0 milestone definitions and success criteria.
- `dependency_map.md` - phase dependencies and AI execution rules.
