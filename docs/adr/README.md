# Architecture Decision Records

ADR files record important architecture and product engineering decisions.

They explain why a decision was made, what alternatives were considered, and what constraints future contributors must respect.

- `ADR-0004-device-adapter-architecture.md`
- `ADR-0005-ai-agent-development-workflow.md`

## Rules

- Add an ADR when a decision affects long-term architecture.
- Do not silently reverse an ADR.
- If a decision changes, create a new ADR that supersedes the old one.
