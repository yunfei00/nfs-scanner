# 商业交付硬件验收矩阵

每个客户版本必须在指定实验室设备上填写并归档本表。自动化测试不能替代真实硬件验收。

| 项目 | 设备/场景 | 验收要求 | 结果 |
| --- | --- | --- | --- |
| 串口发现 | 目标 USB 串口适配器 | 正确显示端口、厂商和描述 | 待验收 |
| 安全连接 | 运动平台 | 启动不自动连接；人工确认后连接 | 待验收 |
| 软限位 | X/Y/Z 上下限 | 越界命令在发送前被拒绝 | 待验收 |
| 正常停止 | 扫描运行中 | 保存已完成点并进入 stopped | 待验收 |
| 软件急停 | 运动运行中 | 控制器收到停止命令，任务记录急停 | 待验收 |
| 掉线 | 扫描与空闲状态 | 不自动重连，不继续发送运动命令 | 待验收 |
| ZNA67 | 指定固件版本 | 搜索、查询、设置、采集、CSV 校验 | 待验收 |
| N9020A | 指定固件版本 | 搜索、查询、设置、采集、CSV 校验 | 待验收 |
| FSW | 指定固件版本 | 搜索、查询、设置、采集、CSV 校验 | 待验收 |
| 断电恢复 | 扫描写入中断电 | 已完成点可读，任务标记 interrupted | 待验收 |
| 长稳测试 | 连续运行 8 小时 | 无线程泄漏、句柄泄漏和数据丢失 | 待验收 |

验收记录必须包含软件版本、构建版本、设备序列号、固件版本、驱动/VISA 版本、执行人和日期。
